# NovaDB Documentation Hub

NovaDB documentation is organized into four core manuals:

| Document | Description |
|---|---|
| [MANUAL.md](MANUAL.md) | **Complete Reference Manual**: SQL dialect, data types, DDL, DML, DQL, Joins, CTEs, Window functions, Vector AI search, All built-in functions, CLI & REPL console, and Rust API. |
| [API.md](API.md) | **Network & Protocol Specification**: PostgreSQL Wire Protocol v3 gateway, HTTP REST Admin API, and Local-First sync relay protocol. |
| [CLIENTS.md](CLIENTS.md) | **Multi-Language Client Guide**: Connection guides and code samples for PHP, Rust, Node.js/TypeScript, Python, Go, Java/Kotlin, C#/.NET, Ruby, C/C++, and cURL. |
| [DEPLOYMENT.md](DEPLOYMENT.md) | **Production Operations Guide**: Systemd service setup, Docker Compose, automated hot backups, disaster recovery, and performance tuning. |
