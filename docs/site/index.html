Quick Start

Up and running in seconds

Build from source using Rust toolchain and start the unified multi-protocol server.

Terminal (Bash) 
# 1. Clone repository and build release binaries
git clone https://github.com/hoangtuvungcao/NovaDB.git
cd NovaDB
cargo build --release

# 2. Start unified server daemon (HTTP 8787 + PostgreSQL Wire 5432)
./target/release/novadb serve \
  --listen 127.0.0.1:8787 \
  --pg-listen 127.0.0.1:5432 \
  --data-dir ./novadb-data

# 3. Connect via psql
psql -h 127.0.0.1 -p 5432 -U admin -d default

# 4. Open Web Admin Studio in browser
# http://127.0.0.1:8787/studio

AI & Embeddings

Built-in Vector Search Engine

Store, index, and compute high-dimensional embedding similarity directly in SQL.

SQL Vector Query 
-- 1. Create table with vector embeddings
CREATE TABLE Documents (
    Id TEXT PRIMARY KEY,
    Content TEXT NOT NULL,
    Embedding BLOB NOT NULL
);

-- 2. Insert float32 binary embeddings from JSON array
INSERT INTO Documents (Id, Content, Embedding)
VALUES ('doc1', 'Artificial Intelligence in Rust', VECTOR_TO_BLOB('[0.15, 0.82, -0.34, 0.91]'));

-- 3. Perform Cosine Similarity Search
SELECT Id, Content,
       VECTOR_COSINE_SIMILARITY(Embedding, VECTOR_TO_BLOB('[0.14, 0.80, -0.32, 0.90]')) AS Similarity
FROM Documents
ORDER BY Similarity DESC
LIMIT 5;

Client Integration

Connect with Any Language

Quick start examples using standard drivers across different ecosystems.

Python (psycopg2) 
import psycopg2

conn = psycopg2.connect(
    host="127.0.0.1",
    port=5432,
    database="default",
    user="admin",
    password=""
)
cur = conn.cursor()
cur.execute("SELECT uuid_v7() AS id, now_iso() AS ts, 'NovaDB' AS name;")
row = cur.fetchone()
print(f"Connected: ID={row[0]}, Time={row[1]}, Name={row[2]}")
cur.close()
conn.close()
