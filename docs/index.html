Quick Start

Get Started in 10 Seconds

Choose your preferred installation method: pre-built binaries, one-line installer script, or build from source.

1. One-Line Installer

Automatically downloads and installs the latest pre-compiled binary for your system architecture without requiring Rust or build tools.

2. Direct Binary Download

Single standalone executable for Windows, Linux, and macOS. Unzip and run immediately with zero external dependencies.

3. Docker Container

Run NovaDB in an isolated container with both HTTP REST (8787) and PostgreSQL Wire (5432) ports exposed.

Option A: 1-Line Automated Installer (Linux & macOS) 
curl -fsSL https://raw.githubusercontent.com/hoangtuvungcao/NovaDB/master/scripts/install.sh | bash
Option B: Windows 1-Line Installer (PowerShell) 
irm https://raw.githubusercontent.com/hoangtuvungcao/NovaDB/master/scripts/install.ps1 | iex
Option C: Launch Server & Connect 
# 1. Start NovaDB server daemon
novadb serve --listen 127.0.0.1:8787 --pg-listen 127.0.0.1:5432 --data-dir ./novadb-data

# 2. Open Web Admin Studio in your browser:
# http://127.0.0.1:8787/studio

# 3. Or connect via psql or GUI (DBeaver, DataGrip, TablePlus):
psql -h 127.0.0.1 -p 5432 -U admin -d default

Core Engine

High-Performance Architecture

NovaDB combines high-throughput concurrent I/O with ACID-compliant SQLite WAL storage.

64MB Page Cache

SQLite PRAGMA cache_size = -64000 caches hot index pages and table data directly in RAM, reducing disk reads.

In-Memory Temp Store

PRAGMA temp_store = MEMORY executes recursive CTEs, temporary tables, and sort operations in RAM without writing temporary files to disk.

256MB Memory-Mapped I/O

PRAGMA mmap_size = 268435456 allows kernel memory-mapping of the database file, minimizing context switches and memory copies.

Multi-Client Connection Pool

NovaDbPool manages thread-safe reader/writer handles with RAII recycling and non-blocking parallel reads across threads.

Deterministic Replication

Hybrid Logical Clocks (HLC) and Last-Writer-Wins (LWW) resolution ensure consistent convergence across offline replicas.

Enterprise Security

Salted SHA-256 password hashing, user activation toggles, and granular table-level RBAC grants.

Universal Compatibility

PostgreSQL Wire Protocol v3 Gateway (Port 5432)

Connect natively with any standard PostgreSQL client, CLI tool, ORM, or database GUI without custom drivers.

GUI Tool Compatibility

Connect seamlessly with DBeaver, DataGrip, TablePlus, pgAdmin, and Navicat. Host: 127.0.0.1, Port: 5432, User: admin, Database: default.

Protocol Coverage

Supports StartupMessage, SSLRequest negotiation, Simple Query Protocol ('Q'), Extended Query Protocol (Parse, Bind, Execute, Sync), and transaction state tracking.

Native Drivers

Direct driver support for Python (psycopg2/asyncpg), Node.js (pg), PHP (pdo_pgsql), Go (pgx), C# (Npgsql), Java (JDBC), and Rust (tokio-postgres).

REST Interface

HTTP Administration & Query API (Port 8787)

Execute SQL queries, batch DDL scripts, manage schemas, and run maintenance operations via JSON endpoints.

HTTP Endpoints (cURL) 
# 1. Execute SQL Query (Returns JSON rows)
POST /v1/admin/databases/:id/query
Body: {"sql": "SELECT uuid_v7() AS id, now_iso() AS ts;"}

# 2. Execute Batch DDL Script
POST /v1/admin/databases/:id/execute
Body: {"sql": "CREATE TABLE Users (Id INT PRIMARY KEY, Name TEXT); INSERT INTO Users VALUES (1, 'Alice');"}

# 3. Inspect Database Schema
GET /v1/admin/databases/:id/schema

# 4. Create Online Hot Backup
POST /v1/admin/databases/:id/backup
Body: {"destination_path": "./novadb-backups/backup.novadb"}

# 5. Check Database Integrity
POST /v1/admin/databases/:id/integrity

# 6. Checkpoint WAL Log
POST /v1/admin/databases/:id/checkpoint

AI & Embeddings

Built-in Vector Search Engine

Store, index, and compute high-dimensional embedding similarity directly in SQL.

SQL Vector Query 
-- 1. Create table with vector embeddings
CREATE TABLE Documents (
    Id TEXT PRIMARY KEY,
    Content TEXT NOT NULL,
    Embedding BLOB NOT NULL
);

-- 2. Insert float32 binary embeddings from JSON array
INSERT INTO Documents (Id, Content, Embedding)
VALUES ('doc1', 'Artificial Intelligence in Rust', VECTOR_TO_BLOB('[0.15, 0.82, -0.34, 0.91]'));

-- 3. Perform Cosine Similarity Search
SELECT Id, Content,
       VECTOR_COSINE_SIMILARITY(Embedding, VECTOR_TO_BLOB('[0.14, 0.80, -0.32, 0.90]')) AS Similarity
FROM Documents
ORDER BY Similarity DESC
LIMIT 5;

Distributed Sync

Local-First Replication & Sync Engine

Deterministic Last-Writer-Wins (LWW) convergence using Hybrid Logical Clocks (HLC).

Atomic Change Capture

Automatic change tracking triggers log all mutations into _novadb_changes with HLC timestamps and device UUIDs.

Deterministic LWW Merge

Tie-breaking tuple (hlc, device_id, change_id) ensures consistent conflict resolution across all distributed nodes.

Sync Relay Protocol

Incremental push/pull synchronization via cursor-based paging with offline-first support.

Client Integration

Connect with Any Language

Quick start examples using standard drivers across different ecosystems.

Python (psycopg2) 
import psycopg2

conn = psycopg2.connect(
    host="127.0.0.1",
    port=5432,
    database="default",
    user="admin",
    password=""
)
cur = conn.cursor()
cur.execute("SELECT uuid_v7() AS id, now_iso() AS ts, 'NovaDB' AS name;")
row = cur.fetchone()
print(f"Connected: ID={row[0]}, Time={row[1]}, Name={row[2]}")
cur.close()
conn.close()

Production Operations

Deployment & Operations

Run NovaDB in production as a Systemd service or with Docker Compose.

Docker Compose (compose.yaml) 
services:
  novadb:
    image: ghcr.io/hoangtuvungcao/novadb:latest
    container_name: novadb
    restart: unless-stopped
    ports:
      - "8787:8787"
      - "5432:5432"
    volumes:
      - novadb_data:/data
    environment:
      - NOVADB_LISTEN=0.0.0.0:8787
      - NOVADB_PG_LISTEN=0.0.0.0:5432
      - NOVADB_DATA_DIR=/data

volumes:
  novadb_data:
